3D 장면과 주거 환경 분석

  • opo-data.ts가 지도·건물·지형을 불러와 좌표를 맞춘다.
  • opo-world.ts가 지형 위에 건물과 길을 그리고 카메라와 이동을 관리한다.
  • OpoTour.tsx에서 시간대별 실외 일조, 방향별 지형과 차폐, 보행 경로와 고도 단면을 연다.

운영과 기록

  • Next.js 정적 결과물과 frontend/worker를 묶어 공개 Sites에 배포한다. 함께 임장의 서버 기능은 Worker와 D1을 쓴다.
  • 송파 개인 체크리스트와 현장 메모는 브라우저에 저장된다.
  • backend/app은 별도의 실험용 FastAPI 코드다. 공개 3D 장면과 기본 분석은 준비된 파일과 브라우저 계산으로 동작한다.

자료와 추정의 경계. 차폐에 필요한 건물 높이가 부족한 경우 일조가 미판정으로 남을 수 있다. 경로 경사는 지형에서 계산하고, 실제 보도 단차·출입 조건과 신호 대기는 현장 확인 항목으로 표시한다.

서울 확장에서 정할 것

시범 단지에서 검증한 생성 과정을 넓힐 때 적용할 설계 항목이다.

  1. 공유 범위와 갱신 단위. 도로·지형·건물을 어느 공간 단위로 묶고 원본이 바뀌면 어떤 단지 결과를 다시 생성할지 정한다.
  2. 3D 장면과 분석의 공개 기준. 경계·주동·좌표·높이 연결을 점검하고, 보행로 단절처럼 남은 자료 부족은 이용자가 결과 화면에서 볼 수 있게 한다.
  3. 현실과 대조할 조건. 지형과 도로의 이음새, 서로 다른 날짜의 그림자, 출입구까지의 보행 연결을 표본에서 검증한다. 단지 간 연속 이동도 별도로 검증한다.
