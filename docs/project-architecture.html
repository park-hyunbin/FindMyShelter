FIND MY SHELTER

집을 보러 가기 전에, 동네를 먼저 걸어보세요

Find My Shelter는 지도와 건축·지형 자료로 아파트 주변을 3D로 만들어 보여줘요. 볕과 그늘, 역에서 집까지의 오르막, 공원까지 이어지는 길을 보면서 현장에서 어디를 볼지 정할 수 있어요.

예를 들어, 겨울 오후에 놀이터에 볕이 들까?

현장에 갈 시간은 한정돼 있어요. 온라인에서 확인할 수 있는 정보를 먼저 보고, 중요한 장소와 시간을 골라 갈 수 있어요.

가락동부센트레빌의 놀이터 옆과 산책로를 비교해요. 날짜를 12월 21일, 시각을 오후 3시로 맞추면 현재 모델에서는 놀이터 옆에 볕이 들고 103·104동 사이 산책로는 인근 주동에 가려져요.

그늘을 만든 주동을 3D에서 확인하고, 관심 지점과 시간을 현장 메모에 남길 수 있어요. 실제 나무 그늘이나 실내 채광은 방문 때 살펴볼 항목이에요.

자료가 3D 화면이 되는 과정

건물, 도로, 지형은 서로 다른 곳에서 받아요. 미리 위치를 맞추고 필요한 만큼 잘라 두면, 브라우저는 선택한 동네의 자료를 읽어 화면을 그릴 수 있어요.

  1. 자료 받기

    단지 목록에는 주소와 동수가 있고, 건축물대장에는 건물 높이가 있어요. 지도에는 길과 건물의 모양이 있어요.

    data/

  2. 같은 위치에 맞추기

    같은 주소와 동 정보를 연결하고, 건물·길·땅의 위치를 한 기준으로 맞춰요. 서로 맞지 않거나 비어 있는 값은 표시해요.

    backend/

  3. 동네별로 묶기

    지도와 건물을 작은 파일로 나누고, 각 단지에서 불러올 자료의 목록을 만들어요.

    frontend/public/datasets/

  4. 화면에서 체험하기

    브라우저에서 건물과 거리를 그리고, 선택한 장소와 시각의 햇빛이나 지형을 살펴봐요.

    frontend/

어떤 자료로 무엇을 알 수 있나

장면을 만드는 자료와 생활 조건을 판단하는 근거가 어디서 왔는지 확인할 수 있어요.

아파트 찾기

K-apt는 공동주택 단지의 이름, 주소, 세대수, 주차 같은 정보를 공개해요. 프로젝트는 단지마다 붙은 코드를 기준으로 검색 목록과 3D 장면을 연결해요.

K-apt 자료 설명 · 검색과 실거래 자료 설명

건물과 햇빛

건물의 위에서 본 모양은 서울시 지도, 높이는 연결된 건축물대장에서 가져와요. 이 자료와 태양 위치를 이용해 어느 건물이나 지형이 빛을 가릴 수 있는지 계산해요. 필요한 높이가 비어 있으면 일조 결과가 미판정으로 남을 수 있어요.

서울 건물과 높이 연결 기록

땅의 높이와 오르막

지형 높이 지도에는 땅의 높이가 격자마다 들어 있어요. 일부 경로는 서울시 등고선과 높이 표본을 더해 오르내림을 계산해요. 연석, 계단, 보도 표면의 실제 경사는 현장에서 확인할 수 있어요.

지형과 보행 경로 대조 기록

길·공원·물길

OpenStreetMap으로 길과 주변 환경의 위치를 찾고 서울시 자료로 도로 폭, 보도, 횡단보도와 보행 신호의 배치를 보강해요. 경로는 연결이 확인된 곳까지 표시하며, 개방 여부와 신호 대기 시간은 추가 확인이 필요해요.

횡단보도·보도·신호 자료 설명

데이터 레이어

미판정
현재 자료로 결과를 확정하기 어려운 상태예요. 예를 들어 햇빛 방향에 높이를 모르는 건물이 있는 경우예요.

아파트가 늘어나면 무엇을 다시 만들어야 할까?

이웃한 아파트는 같은 길과 공원을 바라봐요. 위치가 같은 도로와 지형은 한 번 만들어 공유하고, 선택한 단지에 필요한 정보만 불러오는 구조예요.

서버와 브라우저는 무엇을 하나

검색 화면에서 단지를 누르면 그 동네의 자료만 내려받아요. 화면을 그리고 일조를 계산하는 일은 브라우저에서 해요.

브라우저에서 하는 일

  • Next.js는 목록과 버튼을 보여주고, Three.js는 3D 동네를 그려요.
  • 고른 지점의 햇빛, 보이는 방향과 경사를 계산하거나 준비된 결과를 보여줘요.
  • 송파의 개인 체크리스트와 현장 메모는 사용 중인 브라우저에 저장해요.

배포와 함께 임장

  • 공개 Sites는 준비된 화면과 지도 파일을 보내줘요.
  • 함께 임장의 접속 정보는 Worker와 D1에서 처리해요. Worker는 서버 요청을 받고 D1은 그 기능에 쓰는 데이터베이스예요.
  • 저장소의 backend/app은 별도의 주소 분석 실험 코드예요.

서울 확장에서 정할 것

시범 단지에서 검증한 생성 과정을 넓힐 때 적용할 설계 항목이다.

  1. 공유 범위와 갱신 단위. 도로·지형·건물을 어느 공간 단위로 묶고 원본이 바뀌면 어떤 단지 결과를 다시 생성할지 정한다.
  2. 3D 장면과 분석의 공개 기준. 경계·주동·좌표·높이 연결을 점검하고, 보행로 단절처럼 남은 자료 부족은 이용자가 결과 화면에서 볼 수 있게 한다.
  3. 현실과 대조할 조건. 지형과 도로의 이음새, 서로 다른 날짜의 그림자, 출입구까지의 보행 연결을 표본에서 검증한다. 단지 간 연속 이동도 별도로 검증한다.
