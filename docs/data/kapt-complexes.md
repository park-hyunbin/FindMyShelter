# K-apt 단지 기본정보

아파트를 단지 이름이나 주소로 검색하고 세대수와 주차 같은 기본정보를 보여주기 위해 쓰는 자료입니다. 아래는 검색용 2026-11-13 자료와 가락동부센트레빌의 관리비 공시를 다룹니다. 서울 전체 목록 집계에는 별도의 2026-11-20 자료를 사용했습니다.

[전체 문서 목차](../README.md) · [검색 조건과 실거래](tour-matching.md) · [서울 전체 목록 집계](../planning/2026-11-21-seoul-tour-coverage.md)

사용자 제공 2026-11-13 스냅샷은 `data/raw/complexes/kapt/`에 원본으로 보관합니다. [K-apt 공동주택 단지 기본정보](https://www.data.go.kr/data/15073271/fileData.do)와 같은 단지 단위 자료로, 이 스냅샷의 열에는 난방·관리, 세대수·동수, 주차, 전기차 충전시설, 최고층수 등이 있습니다. 발행 시점의 참고용 자료이므로 현재 상태와 다를 수 있습니다.

```sh
.venv/bin/python -m pip install 'openpyxl>=3.1,<4'   # 처음 한 번
.venv/bin/python backend/scripts/prepare_kapt_complexes.py data/raw/complexes/kapt/20261113_단지_기본정보.xlsx
```

`data/processed/complexes/kapt/20261113_단지_기본정보.csv`가 생성됩니다. 스크립트는 앞의 안내문을 건너뛰고 헤더와 데이터 값을 보존합니다. 식별코드와 우편번호의 앞자리 0을 보존하려면 CSV를 읽는 쪽에서도 해당 열을 문자열로 지정합니다. 빈 값은 모름으로 유지하고 0으로 바꾸지 않습니다. CSV는 로컬 DB 입력으로 관리하며 웹 번들이 읽지 않습니다.

단지를 식별하는 키는 `단지코드`입니다. 건물 윤곽의 `UFID`와는 다른 키이므로, 임장 대상 단지를 연결할 때는 주소를 확인하고 한 단지 코드에 여러 동을 매핑합니다.

| 임장 지역 | K-apt 단지코드 | 원본 도로명주소 |
|---|---|---|
| 가락동부센트레빌 | `A13816002` | 서울특별시 송파구 송파대로32길 33 |
| 오포롯데캐슬포레스트 | `A46492201` | 경기도 광주시 수레실길 7 |

단지 최고층수만으로 102·103동 같은 개별 동의 층수를 정할 수 없습니다. 충전기 설치 대수와 전기차 전용 주차면 수도 다른 항목으로 보관합니다.

## 가락동부센트레빌 월별 관리비

2026-11-19에 [K-apt](https://www.k-apt.go.kr/web/main/index.do)에서 **관리비 → 우리단지 관리비등 조회**를 열어 단지코드 `A13816002`의 2026년 9월 발생분을 확인했습니다. 공시의 단지 전체 금액은 공용관리비 50,523,474원, 개별사용료 33,873,038원, 장기수선충당금 월부과액 12,048,860원으로 합계 96,445,372원입니다. 공용관리비의 주거전용면적 ㎡당 공시 단가 1,481.621155원은 화면에서 원 단위로 반올림합니다. 금액과 발생월은 `frontend/components/data/songpa-grounds.ts`에 기록합니다.
