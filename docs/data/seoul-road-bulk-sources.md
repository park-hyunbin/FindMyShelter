# 서울 전역의 차선·차도 일괄 수집

2026-11-22에 공개 파일을 내려받아 서울 25개 구의 차선과 차도 도형을 비교했다. 서울시 원본을 레이어별로 한 번씩 확보한 뒤, 도시 단위 공간 인덱스에서 단지나 생활권에 필요한 부분을 꺼내 쓰는 방식이다.

| --- | --- |

다섯 기본 도형과 버스전용차로의 좌표계는 EPSG:5186이다. 파일 날짜는 원본 관측일을 보장하지 않으므로 출처, 파일 버전, 관측일과 좌표계를 각각 기록한다. [서울시 차선 자료](https://data.seoul.go.kr/dataList/OA-15537/S/1/datasetView.do) · [에스맵 오픈랩](https://openlab.eseoul.go.kr/) · [2026년 버스전용차로 자료](https://data.seoul.go.kr/dataList/OA-22396/F/1/datasetView.do)

관리번호가 일치한 버스전용차로 중 두 시점의 선형 거리를 계산할 수 있었던 3,032개를 대조했다. 615개는 두 선형의 최대 이격 거리(Hausdorff 거리)가 1m를 넘었고, 그중 414개는 5m를 넘었다. 선형이 이동한 경우와 길이·분할 범위가 달라진 경우가 함께 들어 있는 값이다. 오래된 원본의 차선을 옮겨 맞추기 전에 최신 도형을 확인해야 하는 이유다.

## 서울 전체 1차 대조

길이가 25cm보다 긴 유효 선형이 있는 차선 기록 339,953건을 최대 2m 간격으로 표본화했다. 표본이 차도와 보도 폴리곤 중 어디에 걸치는지 비교한 결과다. 조사한 15,723.1km는 평행 차선 표시를 각각 센 길이이므로 도로 연장을 뜻하지 않는다.

| 표본 위치 | 조사 길이 기준 비율 |
| --- | ---: |
| 차도 면에만 포함 | 88.4% |
| 차도와 보도 면에 모두 포함 | 3.8% |
| 보도 면에만 포함 | 약 0.01% |
| 두 면 밖이지만 차도에서 0.5m 이내 | 2.3% |
| 나머지 차도 밖 | 5.4% |

차도에만 포함되는 비율은 구별로 81.2~92.4%였다. 도로 층위나 방향을 가리지 않은 평면 검사여서, 교량 위 차선이 아래 차도와 겹치는 경우도 있을 수 있다. 누락 원인과 현재 차선 상태는 도로 구간별 연결과 최신 원본으로 검증한다. 기존 공개 장면의 렌더러 탈락 집계는 도로 생성·횡단 표시 절단까지 적용한 별도 지표다. [공개 장면 기준선](road-markings.md#공개-장면-전수-점검)

## 수작업을 줄이는 생성 방식

1. **도시 단위 스냅샷을 먼저 만든다.** 위 파일을 한 캐시에 받고 버전·해시를 기록한다. 보도, 차도, 횡단보도, 중심선, 차선을 도시 공통의 공간 인덱스에 넣고, 배포할 때만 같은 범위의 타일로 자른다. 같은 도로가 여러 단지에 걸려도 한 번 연결한다.
2. **차선을 실제 차도에 연결한 뒤 3D를 만든다.** 차도 폴리곤과 중심선의 관계를 먼저 만들고 도로 구간, 방향, 층위, 차도 경계를 저장한다. 실선 등 길이 방향 표시는 연속으로 겹치는 길이·방향·옆 차도와의 분리 여부로 연결한다. 정지선과 횡단보도는 교차로·진입로의 가로 방향과 경계를 대조한다. 원본의 차선 선형을 보존하고, 접속부의 차도 면만 동일한 근거의 경계에 맞춘다. 다른 층에 겹치거나 후보 도로가 여럿이면 미확정으로 남긴다.
3. **원본 관리번호는 갱신에 쓴다.** 2021년 유효 차선 모두에 `MGRNU`가 있고 `SIXID`는 200,496건에 있다. 도로명 코드 `RN_CDE`는 이 파일의 유효 레코드에서 비어 있다. 관리번호가 같은 최신 레코드는 병합 후보로 사용하고, 한 번호에 여러 조각이 있으면 도형과 범위를 함께 비교한다. 도로 면은 별도 `UFID`를 가지므로 차선 식별자만으로 도로에 연결할 수 없다.
4. **최신 원본과 공개 범위를 분리해서 관리한다.** 서울 25개 구 전체의 최신 T-GIS 선형을 구할 때는 도로마다 문의할 필요 없이 시 전체 스냅샷을 요청한다. 제공 항목은 관리번호, 유형, 도로 구간 및 층위 연결자, 조사·갱신 기준일, 수집 범위와 공개 웹서비스 가공·제공 조건이다. 국토지리정보원 정밀도로지도와 서울형 정밀도로지도는 차로 단위 보강 후보다. 공식 서울형 시범 보도자료의 범위는 상암 약 20km이며 서울 전역의 최신 차선 납품을 입증하지는 않는다. [서울시 공공데이터 제공신청](https://data.seoul.go.kr/etc/offerReqst.do) · [국토지리정보원 정밀도로지도](https://www.data.go.kr/data/15059912/fileData.do) · [서울시 정밀도로지도 시범 자료](https://itskorea.kr/downloadFile.do?fileId=FILE_000000000102013&fileSn=0)
5. **자동 검수 후 근거가 있는 구간을 배포한다.** 출처가 확인된 차선, 원본에서 차선 없음이 확인된 도로, 미수집·불일치 도로를 각각 기록한다. 차선이 잘렸거나 보도·다른 층으로 간 위치를 목록으로 남겨 최신 자료와 대조한다. 공개 타일의 차도와 도색은 같은 구간 연결 결과에서 생성한다. [상세 배포 기준](road-markings.md#배포-전-점검-기준)

서울시에 전달할 요청 내용 예시

> 서울 25개 구의 T-GIS 차선·정지선(`A058_L`)과 횡단보도·노면표시 전체 선형 최신 원본을 GeoPackage 또는 SHP로 받을 수 있는지 확인 요청드립니다. 공개된 2021년 선형에는 이후 변경 내용을 확인하기 어렵습니다. 관리번호, 분류코드, 도로·교차로 연결키, 방향·층위, 설치·변경일, 삭제 이력 또는 변경분, 측량 범위와 좌표계가 필요합니다. 자료는 실제 도로와 보행환경을 보여주는 온라인 3D 임장에 사용합니다. 웹 타일로 가공해 공개 서비스로 제공할 때의 이용 조건도 함께 안내 부탁드립니다.

## 재현 명령

Python 3.11 이상에서 실행한다. 작업 폴더의 `road-source-cache`에는 원본을 저장하고, 결과 JSON에는 자치구별 거리 합계, 도형 개수, CRS, 파일 해시와 번호 일치 건수를 남긴다. 기본 실행은 캐시만 사용하고 `--download`를 붙이면 누락된 원본도 받는다.

```powershell
uv run --with pyshp --with shapely --with pyproj --with openpyxl python backend/scripts/audit_seoul_road_sources.py ../road-source-cache --download --output ../road-source-cache/coverage.json
```
