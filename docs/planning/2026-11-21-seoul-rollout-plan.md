# 서울 전역 3D 온라인 임장 확장안

2026년 11월 21일 · 기획안

## 서울에서 만들 제품

서울 어디서든 후보 아파트를 찾아 단지 전체와 주변 동네를 3D로 걸어보고, 지형과 녹지, 물길, 주변 건물이 생활에 미치는 영향을 같은 조건에서 비교한다. 예를 들어 두 후보를 열어 겨울 오후 산책로에 그늘이 드는 이유를 보고, 퇴근길에 역에서 얼마나 올라와야 하는지 확인한다. 판단에 근거가 된 지점은 3D 화면에서 바로 찾아갈 수 있게 한다.

서울 25개 구를 하나의 제품 범위로 잡는다. 송파에 만든 장면은 엔진과 데이터 규칙을 대조할 때 사용한다. 다음 시험은 지형과 자료 상태가 다른 자치구에서도 같은 방법으로 단지를 생성하는 데 둔다.

## 데이터와 구현 구조

단지는 K-apt 코드로 관리하고, 위치와 주소는 필지고유번호 및 건축물대장과 대조한다. 건물·지형·도로·보행로·녹지·수계는 EPSG:5186의 동일한 기준으로 맞추고, 자료마다 원본 식별자와 기준일을 남긴다. 원본을 갱신할 때는 영향이 있는 공간 타일과 해당 단지의 결과를 다시 생성한다.

| 구성 | 서울 공통으로 만드는 것 | 단지마다 들어가는 정보 |
| --- | --- | --- |
| 3D 지형과 주변 환경 | 지형·건물·도로·보도·횡단보도·녹지·수계를 공간 타일로 만들어 가까운 단지에서 공유한다. 지형, 포장 면, 보도와 교차로는 같은 좌표와 표고 기준에서 접합한다. | 단지 코드, 확인된 경계·주동·출입구, 시작 시점. |
| 길과 건물의 표현 | 도로 폭·차로·교차 구조, 건물 평면·높이·용도처럼 구조화된 항목에 공통 렌더링 규칙을 적용한다. 보행 신호등 위치는 연결 근거가 있을 때 표시한다. | 자료로 확인된 외장재, 입구 형태, 특색 있는 시설 등 표현 보강. |
| 주거 환경 분석 | 날짜·시간·관측 높이, 차폐 범위, 경로와 고도 단면 계산을 공유한다. 분석 자료는 항목에 필요한 거리까지 불러온다. | 비교할 공용 공간과 경로의 출발점·도착점 및 분석 근거. |

사진과 로드뷰는 지도와 건축 자료로 알기 어려운 외관·마감·주변 경관을 확인하는 데 쓴다. 보강 정보는 위치와 출처를 가진 데이터로 등록한다. 지도 경계를 넘어 움직일 때도 인접 타일을 이어서 불러오므로 옆 단지를 새로 추가할 때 같은 도로와 주변 건물을 다시 제작할 필요가 없다.

## 첫 버전에서 공통으로 비교할 항목

| 항목 | 3D에서 확인할 내용 | 결과를 제공할 조건 |
| --- | --- | --- |
| 실외 일조 | 산책로·놀이터·공용 공간의 계절별 직사광과 그늘, 그늘을 만드는 건물이나 지형 | 같은 날짜·시간·관측 높이를 사용한다. 차폐 경로의 건물 높이·지형이 부족한 시각은 미판정으로 표시한다. |
| 지형과 개방감 | 지형 단면, 경사 방향, 눈높이에서 시야를 가리는 지형과 건물 | 지형 해상도와 건물 높이 출처를 표시한다. 지형에서 보간한 고도는 모델 추정으로 표기한다. |
| 공원·수변·역 접근 | 지도에 연결된 길, 구간별 오르내림, 횡단과 계단, 출입구까지 이어지는 범위 | 보행망 연결과 출입구 근거를 확인하고, 근거가 끊기는 지점까지 표시한다. |

위 세 항목은 서울 공통 비교의 첫 범위로 제안한다. 수변과 녹지의 위치는 3D에서 보되, 기온이나 소음을 수치로 비교하려면 관측 또는 검증된 분석 모델을 추가한다. 단지 자료가 충분해지면 통학, 소음·야간 환경과 침수 이력을 같은 흐름에 붙인다. [전체 임장 체크리스트](2026-11-17-complex-online-tour-spec.md#임장-항목별-구현-범위)

## 실행 순서와 확대 기준

1. **서울 25개 구의 목록과 결측을 먼저 공개할 수 있게 만든다.** 단지별로 위치 확인, 3D 진입, 분석 가능 항목을 기록하고 자치구별 집계를 자동 생성한다. 주소·경계·동수·높이·보행 연결 오류를 유형으로 묶어 보완할 원본을 고른다.
2. **서로 다른 환경에서 같은 방식으로 장면을 생성한다.** 송파를 회귀 검증에 쓰고, 평지 밀집형·구릉지·수변·신축을 포함한 4개 이상 자치구에서 총 10곳을 첫 표본으로 삼는다. 생성 기준을 통과하는 단지와 자료 누락 때문에 보류되는 단지를 함께 시험한다. 신규 단지는 같은 명령으로 묶어 생성하고, 단지별 정보는 설정과 원본 데이터로 공급한다.
3. **준비된 장면부터 구 단위로 확대한다.** 주동·경계 정합성과 타일 이음새를 통과한 단지에 3D를 제공한다. 일조와 보행 등은 항목별 근거가 확보된 곳부터 켠다. 단지 목록, 3D, 분석 가능 건수를 자치구별로 표시해 어디까지 사용할 수 있는지 보여준다.

### 첫 표본 완료 기준

- 단지별 렌더러 수정 없이 같은 생성 명령을 실행한다. 같은 입력으로 다시 실행했을 때 같은 단지 ID, 건물 ID, 지형 원점과 결과 파일이 나온다.
- 겹치는 구역에서 건물과 도로의 위치·식별자가 일치한다. 도보로 타일 경계를 지날 때 길과 지면이 끊기거나 높이가 튀는지 3D에서 확인한다.
- 주동 누락, 좌표 또는 높이 오류, 출입구와 경로 단절을 자동 검사한다. 위치·각도·경사 차이는 표본에서 독립 자료와 대조하고, 해결 가능한 오류는 공통 규칙에서 고친다. 수작업은 자료가 충돌한 사례와 화면 표본 확인에 쓴다.
- 두 단지를 같은 조건으로 비교해 일조 차이와 귀갓길의 경사가 생기는 지점을 찾을 수 있다. 사용자가 실제 방문 전에 비교를 해보고, 방문할 후보·시간·경로 중 무엇을 바꿨는지 확인한다.

**첫 개발 범위는 단지 목록과 데이터 상태표, 서울 공통 장면 생성, 여러 구에서의 재현 검증이다.** 외관 작업은 공통 규칙을 개선할 근거가 될 때 우선한다. 첫 표본 10곳과 4개 자치구는 초기 검증 범위를 정하기 위한 제안이다.
