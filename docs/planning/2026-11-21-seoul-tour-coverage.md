장면 건물 수에는 주변 건물도 포함된다. 높이값 비율은 장면 파일의 수치 보유율이다. 관측 지점별 일조 판정 가능 여부는 태양 경로에 걸리는 건물과 지형을 기준으로 계산한다. 보행 기재 건수는 생성된 경로 수이며, 각 경로의 미확인 연결과 현장 확인 범위는 실제 임장 화면에서 본다. 잠실의 두 진입부는 3D 시점 이동에 연결돼 있다.

## 재생성 방법

K-apt 자료실의 기본정보 탭에서 게시물 `137170`에 첨부된 `20261120_단지_기본정보.xlsx`를 사용했다. 저장한 엑셀 파일명을 `kapt-2026-11-20.xlsx`로 두고 저장소 루트에서 실행한다.

```sh
uv run --with openpyxl python backend/scripts/prepare_kapt_complexes.py /path/to/kapt-2026-11-20.xlsx
python backend/scripts/audit_seoul_tour_coverage.py data/processed/complexes/kapt/kapt-2026-11-20.csv --snapshot-date 2026-11-20 --output data/processed/complexes/seoul-tour-coverage.json
```

검사기는 `data/config/buildings`의 `kapt_code`로 기존 장면을 연결한다. 같은 단지코드의 중복 연결, 빠진 자치구, 건물·지형 원점 불일치, 건물 조각의 해시·개수·중복 ID를 발견하면 생성을 중단한다. 출력에는 단지명·단지코드·주소·장면과 자치구 집계가 포함된다. CSV SHA-256은 `77f607c9a5da9ec77b6cd63075b6a14e11ad7141817f2ed94228ef12709730cb`다.

## 단지코드와 건축물대장 연결

11월 20일자 K-apt 목록·필지고유번호와 10월 건축HUB 표제부를 대조했다. **서울 1,963 / 3,158곳, 송파 118 / 161곳**의 주동이 자동 연결 기준을 충족했다. 연결된 서울 주동 11,405개 중 9,051개에 양의 높이값이 있다. 이 비율은 단지 주동의 대장 수치 보유율이다. 일조 계산에는 주변 건물과 지형의 데이터도 필요하다. [K-apt 자료실](https://www.k-apt.go.kr/web/board/webReference/boardList.do) · [건축HUB 표제부](https://www.hub.go.kr/portal/opn/lps/idx-lgcpt-pvsn-srvc-list.do?opnLgcptTaskSeCd=03)

수집기는 K-apt의 등록 필지를 기준점으로 잡고 도로명주소가 정확히 일치하는 세대 보유 주건축물을 찾는다. 같은 법정동과 도로명주소를 공유하는 추가 필지도 후보에 넣어 15개 단지를 연결했다. 동수·세대수와 동명 또는 관리번호의 유일성이 맞아야 자동 연결한다. 두 단지코드에 같은 관리번호가 들어가면 양쪽을 검토 대상으로 보낸다. 동수 차이 444곳, 대장 후보 없음 295곳, 도로명주소 불일치 284곳, 세대수 차이 167곳, 주동 식별자 모호 3곳, 단지코드 간 중복 2곳은 보류했다.

| 송파 확인 사례 | 대조 결과 |
| --- | --- |
| 가락동부센트레빌 | 송파대로32길 33으로 구분한 101~105동 모두 기존 장면의 동명·높이·층수와 일치했다. |
| 가락금호 | 송파대로32길 15의 주거동 8개, 915세대를 연결했다. 세대가 없는 상가동은 제외했다. 한국부동산원 파일에서는 두 가락 단지가 같은 대표 필지고유번호에 모이는 사례가 있었다. [한국부동산원 단지 식별정보](https://www.data.go.kr/data/15106861/fileData.do) |
| 잠실 르엘 | K-apt 필지고유번호와 13개 동의 3D 윤곽은 확인했다. 10월 표제부에서 연결 가능한 주동이 없어 높이 미확인을 유지했다. 송파구 사업 현황에는 2025년 12월 30일 부분준공인가로 기록돼 있다. [송파구 사업 현황](https://www.songpa.go.kr/www/contents.do?key=5802) |

K-apt 필지고유번호 탭의 게시물 `5240`에서 `20261120_단지_필지고유번호.xlsx`를 받는다. 건축HUB의 건축물대장 표제부 2026년 10월 ZIP을 내려받아 실행한다. 검사기는 원본 ZIP에서 필요한 행만 읽는다.

```sh
uv run --with openpyxl python backend/scripts/link_seoul_apartment_register.py \
  data/processed/complexes/kapt/kapt-2026-11-20.csv /path/to/kapt-pnu-2026-11-20.xlsx /path/to/hub-title-202610.zip \
  --snapshot-date 2026-11-20 --register-month 2026-10 --output data/processed/complexes/seoul-register-links.json
```

필지고유번호 엑셀 SHA-256은 `327b29d8266b2c3ae7c9e7a62c574fe64283cb3687fa1da211febb7cd9f4611f`이고, 표제부 ZIP은 `dfab53ee7e07e37f31477d6190b4718564dd860b0de91627e7a4b16562216b7a`다.

## 주동을 지도 윤곽에 연결

서울특별시 에스맵-오픈랩의 건물면 `N1A_B0010000`으로 주동 위치를 확인했다. 도로명·건물 본번·부번·우편번호가 일치하는 주거 윤곽 중 동 이름이 정확히 맞는 것을 연결했다. 단지에 주동과 윤곽이 각각 하나이고 지도에 동명이 없다면 층수가 일치할 때 연결했다. 여러 윤곽이 같은 동 이름을 쓰거나 도형이 깨지면 검토 목록에 남긴다. 지도 층수와 대장이 다른 877개 윤곽에서는 자료별 층수를 따로 기록했다. 3D에 전달하는 높이와 층수는 건축물대장 값을 사용한다. [서울특별시 에스맵-오픈랩 건물면](https://openlab.eseoul.go.kr/qgisplugin/SHP/N1A_B0010000.zip) · [오픈랩 이용 조건](https://openlab.eseoul.go.kr/)

| 범위 | 대장 연결 단지 | 전 주동 윤곽 연결 | 대장 연결 주동 | 윤곽 연결 주동 | 높이값 보유 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 서울 25개 구 | 1,963 | 1,238 | 11,405 | 9,086 | 7,193 |
| 송파구 | 118 | 79 | 1,082 | 959 | 651 |

가락동부센트레빌 5개 동과 가락금호 8개 동 모두 기존 송파 모델에서 가장 많이 겹치는 윤곽의 동 번호와 일치했다. 두 데이터의 교집합을 합집합으로 나눈 면적 비율의 평균은 각각 96.1%, 91.6%였다. 원본 건물면 파일은 2024년 7월 4일자이며, 최신 공사와 신축 단지는 별도 갱신 자료가 필요하다. 잠실 르엘은 해당 건물면 파일에 도로명주소 333의 윤곽을 찾지 못했다. 기존 OSM의 13개 동 윤곽을 근거로 장면을 제공한다.

연결된 서울 건물 윤곽은 UFID당 한 번 저장한다. 아래 명령으로 공유 윤곽과 검토 목록을 생성하고, 가락동부센트레빌·가락금호·잠실엘스의 주변 건물까지 같은 형식으로 잘라 기존 웹 건물 파이프라인을 실행한다. 원본 해시를 비교해 서로 다른 시점의 건물면과 연결 결과가 섞이는 것을 막는다. 주변 건물은 윤곽과 지도 층수를 사용하며, 대장 연결 높이값이 빈 건물의 높이는 비어 있다.

| 송파 샘플 | 범위 내 건물 | 해당 단지 주동 | 범위 내 대장 높이값 보유 |
| --- | ---: | ---: | ---: |
| 가락동부센트레빌 | 1,786 | 5 | 22 |
| 가락금호 | 1,455 | 8 | 15 |
| 잠실엘스 | 1,407 | 72 | 73 |

가락 두 단지의 영역이 겹치는 건물 1,292개는 각 웹 조각에서 식별자, 윤곽, 속성이 모두 같았다. 웹 조각의 해시, 건물 수와 지형 결합에 사용할 EPSG:5186 원점도 검증했다.

```sh
uv run --with openpyxl --with pyshp --with pyproj --with shapely python backend/scripts/match_seoul_building_footprints.py \
  data/processed/complexes/seoul-register-links.json /path/to/N1A_B0010000.zip --output-dir data/processed/complexes/seoul-footprints
uv run --with openpyxl --with pyshp --with pyproj --with shapely python backend/scripts/prepare_seoul_building_windows.py \
  data/processed/complexes/seoul-footprints /path/to/N1A_B0010000.zip --complex A13816002 --complex A13880407 --complex A13822004 \
  --output-dir data/processed/complexes/seoul-building-windows
for code in A13816002 A13880407 A13822004; do
  uv run --with geopandas --with shapely --with pyproj python -m backend.pipeline build-geojson \
    --config "data/processed/complexes/seoul-building-windows/$code/config.json"
done
```

이번 생성 범위는 건물 데이터다. 웹에서 단지 밖까지 이어지는 임장으로 연결하려면 동일 좌표계의 지형, 도로·보행, 녹지 데이터를 같은 범위에 맞춘다. 자치구별 보행망과 일조 분석 범위는 공통 공간 조각이 생성된 뒤 집계한다.
